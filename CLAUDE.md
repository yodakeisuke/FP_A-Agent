## Project Overview

This is an AI agent scaffold integrating Ax (DSPy), Vercel AI SDK, LangWatch, Promptfoo, React 19, and Next.js 16. The project provides both a CLI agent and a web UI, with Agentic Context Engineering (ACE) for prompt optimization.

## Development Commands

### Frontend (Next.js)
```bash
npm run dev          # Start Next.js dev server with Turbo on http://localhost:3000
npm run build        # Build Next.js for production
npm start            # Start production server
```

### CLI Agent
```bash
npm run agent        # Build and run the CLI agent (builds TypeScript, then executes)
npm run agent:build  # Compile TypeScript to dist/ without running
npm run agent:run    # Run the already-built CLI bundle
npm run agent:watch  # Rebuild on file changes (for development)

# CLI usage examples:
node dist/index.js --json "Your message here"   # Returns JSON output with message + metadata
node dist/index.js --text "Your message here"   # Returns plain text only
```

### ACE Workflow
```bash
npm run ace:compile  # Build CLI and run ACE optimizer to update ace-artifact.json
```
- ACE optimizer reads `src/ace/dataset.ts` and updates `ace-artifact.json` with improved playbook
- Runtime loads `ace-artifact.json` if present; otherwise uses seed playbook from `src/ace/index.ts`
- Modify `src/ace/dataset.ts` to steer ACE refinements

### Testing & Quality
```bash
npm run lint                # Run Biome linter/formatter
npm run promptfoo:eval      # Run Promptfoo evaluation suite
```

## Architecture

### TypeScript Configurations
- **tsconfig.json**: Next.js frontend configuration with `module: "esnext"` and `moduleResolution: "bundler"`
- **tsconfig.cli.json**: CLI compilation with `module: "esnext"`, outputs to `dist/`

### Core Agent Flow

#### Entry Points
- **CLI**: `src/index.ts` → `src/agent/agent.ts::runAgent()`
- **Web UI**: `app/api/agent-chat/route.ts` → `src/agent/agent.ts::runAgent()`

#### Agent Execution (`src/agent/agent.ts::runAgent()`)
1. LangWatch observability setup (`ensureLangWatch()`, `getTracer()`)
2. `generateAceReply()`: Loads ACE playbook (artifact or seed) → creates Ax program → applies playbook → runs LLM inference
3. Returns `AgentResult` with message content and ACE/LLM metadata

### ACE (Agentic Context Engineering)

**Playbook System** (`src/ace/`):
- `index.ts`: Defines DEFAULT_PLAYBOOK with Mission, Mindset, and Skills sections
- `program.ts`: Creates Ax program with BASE_INSTRUCTION, applies playbook sections as prompt instructions
- `compile.ts`: ACE optimizer that refines playbook based on dataset feedback
- `dataset.ts`: Training examples and metric for ACE optimization

**Artifact Loading**:
- Checks for `ace-artifact.json` (generated by `npm run ace:compile`)
- Falls back to DEFAULT_PLAYBOOK if artifact not found
- Playbook sections are appended to program description as Markdown-formatted instructions

### Frontend Structure

**App Router** (`app/`):
- `page.tsx`: Main chat interface
- `api/agent-chat/route.ts`: Streaming API endpoint using Vercel AI SDK's `createUIMessageStream`
- `components/ai-elements/`: Conversation, Message, PromptInput components
- `components/chat/`: Prompt suggestion chips
- `components/ui/`: shadcn/ui components (Button, Input, Dialog, etc.)
- `hooks/use-agent-chat.ts`: Chat state management

### Shared Types (`src/shared/agent-types.ts`)

```typescript
AgentResult {
  message: string
  meta: { model: string, usedLiveModel: boolean, ace?: { playbookVersion, source } }
}
```

### Observability

**LangWatch** (`src/agent/observability.ts`):
- Initializes only when `LANGWATCH_API_KEY` is set
- Tracer name defaults to "fp_a-agent" (override with `LANGWATCH_SERVICE_NAME`)
- Wraps agent execution in spans for tracing

## Environment Variables

Required:
- `OPENAI_API_KEY`: OpenAI API key for LLM inference

Optional:
- `LANGWATCH_API_KEY`: Enable LangWatch tracing
- `LANGWATCH_SERVICE_NAME`: Custom service name (default: "fp_a-agent")
- `ACE_ARTIFACT_FILENAME`: Override artifact filename (default: "ace-artifact.json")
- `ACE_ARTIFACT_DIR`: Override artifact directory (default: project root)

## Code Style

- **Biome**: Double quotes, semicolons avoided (ASI-style), 2-space indentation
- **Import Organization**: Biome auto-organizes imports on save
- **Tailwind**: CSS directives enabled in Biome config

## Key Design Patterns

1. **Dual Entry Points**: Same `runAgent()` function powers both CLI and web UI
2. **Streaming UI**: Web UI uses Vercel AI SDK's message streaming protocol
3. **ACE Integration**: Playbook sections are injected into Ax program description as structured instructions
4. **Type Safety**: Shared types between frontend/backend via `src/shared/`

## Testing Strategy

**Promptfoo** (`promptfooconfig.yaml`):
- Uses `exec:` provider to test compiled CLI bundle
- State stored in `.promptfoo-home/` for sandboxed environments
- Outbound telemetry disabled by default
- Test assertions check greeting behavior and expected metadata shape
